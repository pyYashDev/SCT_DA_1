# SkillCraft Technology - Task 01: Excel Sales Dashboard

## 📊 Project Overview

This project was completed as **Task 01 during my SkillCraft Technology internship**.

The objective of this task was to clean, analyze, and visualize Superstore sales data using Microsoft Excel and create an interactive sales dashboard.

## 🎯 Objectives

* Analyze total sales and revenue
* Analyze profit by category
* Analyze sales by category and region
* Identify monthly sales trends
* Identify top-performing products
* Create an interactive dashboard
* Use conditional formatting to highlight performance

## 🛠️ Tools Used

* Microsoft Excel
* Excel Tables
* PivotTables
* PivotCharts
* Slicers
* Conditional Formatting
* Data Cleaning
* Data Visualization

## 📈 Dashboard

The dashboard includes:

* Total Orders
* Total Revenue
* Average Sales
* Total Profit
* Profit by Category
* Sales by Region
* Sales by Category
* Monthly Sales Trend
* Top 10 Products by Sales
* Interactive Category, Month, and Region slicers

## 💡 Key Learning

This project helped me gain practical experience in using Excel for data cleaning, analysis, visualization, and dashboard creation.
